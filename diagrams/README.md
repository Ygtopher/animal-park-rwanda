# Project Diagrams

This folder contains the visual diagrams for the Animal Park Rwanda project presentation.

## Diagrams Included

### 1. Activity Diagram - Booking Process
**File:** `activity_diagram.png`

Shows the complete user booking flow from browsing parks to receiving confirmation.

**Key Elements:**
- User journey through the booking system
- Decision points (login check, availability, payment success)
- Error handling and retry loops
- Success path to confirmation

---

### 2. Data Flow Diagram (DFD)
**File:** `data_flow_diagram.png`

Illustrates how data flows through the Animal Park management system.

**Components:**
- External Entities: User, Admin, Ranger
- Processes: Authentication, Park Management, Booking, Payment, Analytics
- Data Stores: Users, Parks, Reservations, Payments, Animals databases

---

### 3. Sequence Diagram - Reservation Flow
**File:** `sequence_diagram.png`

Details the step-by-step interaction between system components during reservation.

**Participants:**
- User
- Frontend (React Application)
- API Server
- Authentication Service
- Database
- Payment Gateway

---

## Usage

These diagrams are ready for use in:
- PowerPoint presentations
- Project documentation
- Exam demonstrations
- Technical reports

## Diagram Standards

- **Activity Diagram:** UML 2.5 notation
- **Data Flow Diagram:** Yourdon-DeMarco notation
- **Sequence Diagram:** UML 2.5 notation

All diagrams are high-resolution and presentation-ready.
